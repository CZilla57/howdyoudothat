# Marketing screenshot prompt set

Generated with the built-in image generation tool in `ads-marketing` edit
mode. Each original screenshot was the UI edit target; the first generated
creative became the visual reference for the remaining campaign.

## Shared direction

Rebuild the supplied app screenshot as a premium, playful iOS App Store
creative for “How’d You Do That?”. Preserve the app interface exactly and
legibly inside one realistic, centered iPhone. Use a warm coral-orange brand
background, subtle cream radial glow, sparse feature-specific line doodles,
friendly rounded white display type, generous safe margins, and a soft device
shadow. Avoid extra UI, duplicate phones, people, hands, logos, and watermarks.

## Campaign copy

1. Eyebrow: “STEP ONE” — Headline: “Pick the damage.”
2. Eyebrow: “STEP TWO” — Headline: “Tell the boring truth.”
3. Eyebrow: “STEP THREE” — Headline: “Pick your vibe.”
4. Eyebrow: “FINE-TUNE IT” — Headline: “Turn up the chaos.”
5. Eyebrow: “THE PAYOFF” — Headline: “Get the better story.”
6. Eyebrow: “KEEP THE GOOD ONES” — Headline: “Reroll. Save. Share.”

The fifth and sixth prompts additionally required the original story to remain
short and structurally clean, all result actions to remain visible, and no
content to be obscured by the tab bar.
